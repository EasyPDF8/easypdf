What is a PDF Splitter?

A PDF splitter lets you extract specific pages from a PDF document or divide a large PDF into multiple smaller files. Our free online tool offers two modes: custom page selection or fixed interval splitting. No software installation needed.

Frequently Asked Questions About Splitting PDFs

What is the difference between Custom Select and Fixed Interval?
Custom Select lets you pick individual pages manually. Fixed Interval automatically splits the PDF every X pages (e.g., every 5 pages creates separate files with 5 pages each).
Can I extract non-consecutive pages?
Yes! In Custom Select mode, you can select any combination of pages (e.g., pages 1, 3, 5, 10). The tool will extract only the pages you select.
What happens in Fixed Interval mode?
If you enter "5", the tool creates files with 5 pages each: File 1 = pages 1-5, File 2 = pages 6-10, etc. The last file may have fewer pages.
Is there a page limit for splitting?
Yes, the PDF cannot exceed 100 pages per file. This ensures fast processing and stable performance for all users.
What happens if my PDF has more than 100 pages?
The file will be rejected with a clear error message. Please use our Split PDF tool to split it into smaller parts first.
